# Installierbare PWA-Musteranwendung

Über HTTPS oder localhost öffnen; erster vollständiger Online-Aufruf baut eigenen Cache auf. Anschließend Netzwerk ausschalten, neu öffnen und rechnen/exportieren. file:// unterstützt die lokale HTML, nicht die PWA-Installation. Browser-/OS-Installationsweg und Speicherräumung beachten. Keine echte Buchung und kein Modellaufruf.

Manifest und SW verwenden relative Pfade für ein GitHub-Pages-Projekt-Unterverzeichnis. Icons sind deterministische eigene Vektorgrafiken, keine KI-Illustrationen. Vorlage ist technisch im Browser geprüft, nicht auf allen echten Endgeräten.
