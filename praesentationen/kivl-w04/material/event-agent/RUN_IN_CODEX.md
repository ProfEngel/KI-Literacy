# Direktauftrag in Codex — ohne UI

Öffne ausschließlich den kopierten Event-Agent-Ordner. Wähle zunächst das tatsächlich verfügbare Laufzeitmodell; Codex ist der Harness, Luna/Sol oder ein angebundenes lokales Modell das Modell. Ein Frontiermodell kann das Paket zuvor erweitern, darf aber im Benchmark nicht heimlich einspringen.

## Kurzer Prüfauftrag

Lies AGENTS.md. Prüfe Event E01 in Projekt P01 mit den aktuellen lokalen Daten. Rufe die deterministischen Werkzeuge wirklich auf. Zeige Kostenzerlegung, Regelbefunde, Quellen und fehlende Angaben. Buche und versende nichts. Bewahre Originale. Speichere nur einen getrennten Vorschlag mit neuem Dateinamen und einen Prüfbericht. Weise auf die noch nötige menschliche Prüfung hin.

Das ist eine normale Texteingabe, kein registrierter Slash-Befehl.

## Erweiterungsauftrag

Verbessere den Event-Agenten gezielt anhand des beigefügten Fehlerbefunds. Trenne Rolle, deterministische Tools, Daten, Memory und UI. Bleibe unter 1600 Zeichen im kompakten Basishandbuch als Projektkonvention, nicht als bewiesenes allgemeines Optimum. Keine Originaldaten überschreiben. Versioniere die Änderung. Führe bekannte Regressionstests und einen neuen Transferfall aus. Zeige tatsächliche Toolbefunde, keine erfundenen Erfolgsraten.

## Kleiner Laufzeitkandidat

Nach dem Bauen einen neuen Testlauf im Mini-/lokalen Modell beginnen. Agenten-/Tool-/Datenversion, Memory-Ausgangszustand und Konfiguration festhalten. Acht Kernfälle live; vollständiger 30-Fälle-Katalog für Abnahme. Alle Modellurteile anhand der Nachweise prüfen. Datei- und Toolzugang sind nicht automatisch identisch zwischen ChatGPT Chat, Work, Codex und jeder lokalen Oberfläche.
