SCHRITT 03 · DEPLOYMENT-BRÜCKE

Upload-Befähigung für Codex (gh auth login)

Damit Ihr Coding-Agent Projekte direkt auf Ihr GitHub-Konto übertragen kann, verbinden wir Terminal und GitHub über den sicheren Browser-Flow.

  • Identität prüfen: git config --global user.name & user.email setzen.
  • Browser-Login: gh auth login starten → HTTPS → Login with a web browser.
  • Human-in-the-Loop (HITL): Vor jedem git push nennt der Agent Ziel-Repo, Dateiliste und Sichtbarkeit und wartet auf Ihre Bestätigung.

🛡️ Governance-Regel: Niemals Passwörter, 2FA-Codes oder Personal Access Tokens in einen KI-Chat tippen! Authentifizierung läuft ausschließlich über den System-Login.

SCHRITT 04 · ERSTES DEMO-REPO

Cross-Platform PWA: „KI-Lernwerkstatt“

Wir bauen das Repo ki-lernwerkstatt-pwa als offline-fähige Progressive Web App für iOS, Android, macOS und Windows.

  • 3 interaktive Module: (1) BWL-Karteikarten-Trainer, (2) ROI-/Amortisations-Simulator mit Live-Sliders, (3) lokaler JSON-Export/Import.
  • PWA-Technik lokal: index.html, manifest.webmanifest, sw.js (Service Worker Cache) und SVG/PNG-Icons mit relativen Pfaden (./).
  • Überall installierbar: iPhone/iPad (Teilen → Zum Home-Bildschirm), Android, macOS (Zum Dock) & Windows (Edge/Chrome App-Symbol).

💡 W03/W04-Brücke: Deterministische BWL-Rechenlogik läuft 100 % lokal und kostenlos im Browser – ohne laufende API-Kosten!

VISUELLES AGENTEN-LABOR 3 / 3 · KONZIL, ROI-RECHNER & BIG PICTURE (FOLIEN 20–31 KOMPAKT)

Multi-Agenten-Konzil, BWL-Kostenrechner & Gesamtarchitektur

Warum zwei spezialisierte Agenten besser prüfen als einer

Wie bei einer Fallkonferenz im Krankenhaus (Radiologie + Chirurgie + Innere Medizin) trennen wir Planung und Prüfung. Beide teilen das Projektwissen, aber nicht ihr privates Gedächtnis:

👷 Worker 1: Eventplaner

Erstellt den konkreten Raum- und Cateringvorschlag samt Quellenbelegen.

🕵️ Worker 2: Planprüfer

Prüft unabhängig auf Budget-, Kapazitäts- und Sicherheitsverstöße.

👩‍💼 Mensch (HITL)

Sieht Konfliktliste auf einen Blick und trifft die finale Freigabeentscheidung.

Frontier baut die Werkstatt — Mini- oder Lokal-Modell arbeitet im Alltag

A · Alles mit Frontier-Modell 90,00 € / Monat ca. 0,18 € je komplexem Agentenlauf
B · Frontier baut + Mini/Lokal führt aus 7,50 € / Monat Ersparnis: 82,50 € (-92 %) · Lokal per Ollama: 0 € variabel

Die 6-Stufen-Kette für vertrauenswürdige KI im Unternehmen

1. Klare Rolle → 2. Geprüftes Wissen → 3. Deterministische Tools → 4. Härtetest → 5. Modellvergleich → 6. Menschliche Freigabe (HITL).

📌 Merksatz für die Klausur & Praxis: Ein schöner Einzellauf ist noch keine Abnahme. Vertrauen entsteht erst durch messbare Regeln, Werkzeuge und wiederholbare Prüffälle.
