# Regeln für fiktive Events

Preise sind fiktive Endpreise. Raumkosten minutengenau, Endbeträge kaufmännisch auf Cent. Kapazität, Barrierefreiheit, Öffnungszeiten, Belegungen und Catering-Mindestmenge prüfen. Angrenzende Termine erlaubt. Ende muss am selben Tag nach Beginn liegen. Keine ungefragten Änderungen an Teilnehmerzahl, Budget oder Termin. Fehlende Angaben erfragen. Bestätigte Projektkorrekturen aus Memory abrufen; unbestätigte Dokumentnotizen nicht automatisch übernehmen. Keine externe Buchung, kein Versand.
