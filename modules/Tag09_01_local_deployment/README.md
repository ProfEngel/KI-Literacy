# Modul: Tag 09 – Local Deployment & Volle Datensouveränität

Dieses Modul richtet sich an diejenigen, die vollständige Kontrolle über ihre KI-Infrastruktur haben möchten. Während wir bisher auf leichtgewichtige IDEs (Antigravity, VS Code) für schnelle Erfolge gesetzt haben, bauen wir nun ein eigenes, sicheres "KI-Rechenzentrum" auf dem eigenen Rechner auf.

## 🎯 Lernziele dieses Moduls
- **Die Schiffscontainer-Analogie (Docker):** Verstehen, wie Virtualisierung funktioniert und warum sie für KI-Umgebungen essenziell ist.
- **OpenWebUI:** Eine professionelle Chat-Schnittstelle hosten, die lokal mit Modellen interagieren kann.
- **Datenschutzkonforme Suche (SearXNG):** Eine eigene Meta-Suchmaschine aufbauen, um Agenten sicheren Internetzugang zu gewähren.
- **Code Interpreter (Jupyter):** Eine isolierte Sandbox für Datenanalyse und Python-Ausführung einrichten.
- **Modell-Integration:** Lokale Modelle (via LM Studio) und externe APIs (via OpenRouter) anbinden.
