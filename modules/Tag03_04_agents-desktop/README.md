# Modul: Agents Desktop – KI-Agenten in der professionellen Arbeitsumgebung

Dieses Modul fokussiert sich auf die Integration von autonomen KI-Agenten in die professionelle Desktop-Arbeitsumgebung. Wir untersuchen, wie **Agentic Workflows** die Erledigung komplexer Tasks – von Recherche über Codierung bis zur Datenvisualisierung – fundamental verändern.

## Die Single Source of Truth

- **[vorlesungsbegleiter.md](./vorlesungsbegleiter.md)**: Dies ist der Master-Guide für das gesamte Modul. Er führt dich durch das technische Setup (Antigravity & VS Code), zeigt dir, wie Agenten mit "Graphify" semantischen Kontext aufbauen, und beinhaltet ein Praxis-Labor für eigene KI-Projekte (Paper, WebApp, Dashboard). **Starte hier!**

## Themen im Überblick
*   **Track A**: Antigravity für Google Abonnenten.
*   **Track B**: VS Code & Codex (inkl. GitHub Copilot Chat mit OAI-Kompatibilität & ClaudeCode CLI).
*   **Graphify**: Semantische Wissensgraphen zur Token-Ersparnis und Kontext-Sicherung.
*   **Agentic Projects**: "Human-in-the-Loop" Workflows für echte Praxis-Anwendungen.
